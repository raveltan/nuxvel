# @nuxvel/cli

The `nuxvel` command for nuxvel apps: dev services, migrations, generators, tests, builds and deploys to a VPS.

A new app from `npm create nuxvel@latest` installs it. Run `./nv --help` in the app for the commands. See the [CLI docs](https://github.com/raveltan/nuxvel/blob/main/docs/cli.md).
