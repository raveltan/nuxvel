# Translations (`locales/`)

Library: `nuxt-i18n-micro`. Locales: `i18n.locales` in `nuxt.config.ts` (`en`, `zh`). Default `en` has no prefix. `zh` pages are at `/zh/...`.

## Files

| File | Holds |
|---|---|
| `locales/en.json`, `locales/zh.json` | global keys, for each page, layout, component, mail and story |
| `locales/pages/<route>/<locale>.json` | keys of one page. Storybook does not load them, so a component key goes in the global file |

Add each new key to each locale file. Nest keys: `"post": { "title": "Title" }` → `post.title`. Placeholder: `"Hi {name}"`.

## In `app/`

| Name | Use |
|---|---|
| `$t("post.title")` | text in a template |
| `$ts("post.title")` | a prop that needs a string: `:label="$ts('post.save')"` |
| `useI18n()` | `{ ts, localeRoute, getLocale, switchLocale }` in a script. `useSeo(() => ({ title: ts("post.title") }))` |
| `<i18n-t keypath="…">` | markup inside a text: `<template #email><strong>…</strong></template>` for `{email}` |
| `$localeRoute({ name: 'post-id', params: { id } })` | link that keeps the locale. `{ name }` alone opens the `en` page |
| `useUiLocale()` | `<UApp :locale>` in `app.vue` and `error.vue` |
| `<LocaleSwitcher>` | in each layout. Saves `user.locale` with `authClient.updateUser`. Hidden with one locale |

`make:resource --ui` writes English text and `{ name }` links. Change them to `$t` and `$localeRoute` when the app is multilingual.

## On the server

| Name | Use |
|---|---|
| `currentLocale()` | locale of the request. `ctx.locale` in a procedure, `{ locale }` in an action handler |
| `$mails.x.send(data, { locale })` | mail in a locale. Default: `currentLocale()`. Template uses `$t` |
| `user.locale` | the auth mails and notification mails use it |

Zod messages follow the request locale.

## Tests

`actingAs(user, { locale: "zh" })`, `guest({ locale: "zh" })`, `visit("/posts", { locale: "zh" })`. A story: `parameters: { locale: "zh" }`.

## Only English

Remove `zh` from `i18n.locales` and delete `locales/zh.json`.
