# @nuxvel/nuxt

The nuxvel Nuxt module. It gives a Nuxt app a backend: a Postgres database with Drizzle, a typed tRPC API, Zod validation, Better Auth, actions, queues, mail, storage and realtime.

Start a new app with `npm create nuxvel@latest my-app`. See the [nuxvel docs](https://github.com/raveltan/nuxvel/blob/main/docs/index.md).
