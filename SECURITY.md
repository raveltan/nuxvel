# Security policy

## Reporting a vulnerability

Report a vulnerability in private, through a GitHub security advisory. Do not open a public issue, pull request or discussion for it.

1. Open the **Security** tab of the nuxvel repository on GitHub.
2. Click **Report a vulnerability**.
3. Describe the problem, the affected package and version, and the steps that reproduce it.

The maintainers acknowledge each report within 3 business days.

## Supported versions

| Package | Supported |
|---|---|
| `@nuxvel/nuxt` | The latest release of each supported major version |
| `@nuxvel/cli` | The latest release of each supported major version |
| `create-nuxvel` | The latest release |

## Fixes and advisories

The maintainers release a fix for every supported major version at the same time. The GitHub security advisory is published together with the fix releases.
